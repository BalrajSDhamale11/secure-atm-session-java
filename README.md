# Secure ATM Session Simulator (Java)

## Description
This is a console-based Secure ATM Session Simulator developed using Java.  
The project demonstrates core programming concepts such as loops, conditionals, input validation, and menu-driven programs.

## Features
- Email and PIN based login system
- Limited login attempts for security
- Random initial account balance
- Check balance, deposit, and withdraw options
- Minimum and maximum balance constraints
- Menu-driven user interaction

## Technologies Used
- Java
- Scanner class for input
- Random class for balance simulation

## How to Run
1. Compile the program:
   javac SecureATMSession.java
2. Run the program:
   java SecureATMSession

## Learning Outcomes
- Practiced control flow using loops and switch statements
- Implemented input validation and basic security checks
- Improved understanding of real-world logic simulation using Java
